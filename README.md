One emoji that stands for wowo, a Muse personal assistant: 🧭 (compass).
Wowo navigates tasks, finds the way through the work, and guides the boss —
the compass is that portrait in one glyph. It reads instantly at any size,
says something specific about how the agent works (navigation, direction,
guidance), and stays far from the obvious robot, brain, or gear picks.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (the glyph alone, 4 bytes UTF-8),
then verifies the written bytes by reading them back.

## Layout

- `main.py` — writes 🧭 to `/output/entry.txt` and verifies the read-back (stdlib only)
- `entry.txt` — the program's output, for reference
- `CANDIDATES.md` — 10 candidate emojis, each scored against the judge's five criteria
- `prompt.txt` — the brief this entry was built from
